# ai-experiments

This is where my AI's tryout cool things.

## Projects

- **[platefit/](platefit/)** — a Python CLI for bioanalytical plate analysis: fits 4PL/5PL/semilog standard curves, back-calculates sample concentrations with out-of-range flagging, and decomposes within- and between-run variance (the SoftMax Pro + JMP workflow, scripted).
- **[katmai-bears/](katmai-bears/)** — a React PWA dashboard of the Katmai / Brooks Falls live bear cams: fullscreen + swipe between feeds, a live bear counter, fish-catch clips, a daily reel, and Bearapalooza alerts.
- **The minimalist-apps family** — small, quiet apps done well ([arcade-site/](arcade-site/) is the brand site; strategy in `MINIMALIST-APPS-STRATEGY.md`): [hive/](hive/) and [lex/](lex/) (two-player games), [sudoku/](sudoku/), [breakout/](breakout/) (Bricks), [stillness/](stillness/), [tafl/](tafl/), [checkers/](checkers/) — all on the shared [parlor/](parlor/) platform, stamped by [tools/create-app/](tools/create-app/).
