# Checkers (checkers/)

Draughts, plain and sharp — for two.

Checkers is American checkers (English draughts) as a two-player PWA on
the `@parlor/*` platform: free hot-seat on one device, online play with
a friend through invite links, challenges, and async move clocks. The
rules kernel is pure and server-authoritative — mandatory captures,
multi-jumps, and crowning are the engine's verdicts, never the UI's.

Stamped from tafl/ by tools/create-app and morphed per
`tools/create-app/PLAYBOOK.md`; remaining gates in `DONE.md`.

Start with `CLAUDE.md` (rules + commands); design in `DESIGN.md`.
